# Frontend Mentor - Manage landing page

## Project summary

A responsive landing page built for the Manage landing page challenge on Frontend Mentor. The page presents a product overview, key features, customer testimonials, and a newsletter signup area. It includes a mobile navigation menu, a horizontal testimonial slider with navigation dots, and client-side email validation with inline error messages.

## Links
Live Site: https://lupef.github.io/Manage-landing-Page/
Repo: https://github.com/LupeF/Manage-landing-Page

## Technologies used

- **HTML5** for page structure and content.
- **CSS3 and Sass (SCSS)** for styling, with styles organized into component and typography partials.
- **Flexbox and CSS Grid** for layout, with media queries to adapt the page to different screen sizes.
- **Vanilla JavaScript** for menu interactions, testimonial navigation, and email validation.
- **Google Fonts** for the Be Vietnam Pro typeface.

## Challenge

This project is based on the [Manage landing page challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/manage-landing-page-SLXqC6P5).
